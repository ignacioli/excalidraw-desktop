# Local Version History 文档同步清单

## 用途与当前状态

本清单用于跨实现切片维护公共文档的一致性。它记录每个切片需要检查的文档责任、证据和发布边界；它不是功能实现证明，也不替代测试、原生验收、视觉验收或产品负责人接受。

当前功能尚未实现。因此，在对应运行行为、接口或验收证据真实存在以前，公共文档不得宣称 Local Version History 可用，不得写入未实现的命令、菜单、存储结果、错误结果或恢复保证，也不得为这些内容预留空章节。实现完成前只维护本清单和现有文档中已经被代码证明的内容。

### 语言规则

- 普通正文、标题和用户说明使用自然简体中文；English 文件仍是项目要求的 canonical 文件，不做机械逐句翻译。
- 稳定技术标识符保持原样：`history_*` 命令、IPC v3、错误码、事件名、路径、命令和 `File → Version History…` 不翻译或改写。
- 中文文档必须保留与 English 文档相同的行为边界、失败语义、限制和验证状态；翻译不能扩大支持范围。
- 本 feature 不增加完整产品双语范围；只同步项目文档地图要求的架构、quickstart 和必要用户说明。

## 每个实现切片的同步清单

使用规则：切片完成前逐项检查；只有实现、测试/证据和文档回读均完成，才可将对应项标为完成。`未涉及` 必须基于代码 diff 和契约审查，而不是因为暂时没有文档改动就默认成立。

### 准备阶段：T001–T005

- [ ] 保持公共文档的当前事实边界：不发布尚未实现的历史 UI、菜单、IPC、数据库或恢复行为。
- [ ] 确认本清单只维护在 `docs/evidence/local-version-history-docs-checklist.md`；不把 private specs 的 `spec.md`、`plan.md` 或 `tasks.md` 内容复制成公共产品承诺。
- [ ] 记录后续切片的文档 owner、受影响文件和完成证据；不要为尚未有内容的功能创建公共文档空章节。

### 共享基础：T006–T017

- [ ] `docs/contracts/ipc-contracts.md`：仅在 IPC v3 类型、命令、错误码、事件、输入验证或握手实际落地并有契约测试后更新；未注册/未实现命令不得写入可用接口列表。
- [ ] `docs/architecture.md` 与 `docs/architecture.zh.md`：在身份、独立历史存储、对象完整性、统一发布/保留、引用保护、替换状态机或故障屏障实现后，同步记录真实边界和失败状态。
- [ ] `docs/quickstart.md` 与 `docs/quickstart.zh.md`：仅补充已能运行的开发/测试前提或命令；不提前增加用户历史流程，也不把研究 harness 当作产品命令。
- [ ] `README.md` 与 `README.zh.md`：通常标记为未涉及；除非已有实现使用户需要新的最小入口说明，否则不改动。
- [ ] 回读上述受影响文件，确认没有把 `history_*` 设计草案、计划中的状态或测试屏障描述成生产能力。

### User Story 1：浏览、预览和恢复：T018–T025

- [ ] IPC 契约同步列表、预览、恢复和操作状态的已实现字段、分页上限、请求身份、错误/不可用项和响应丢失查询规则。
- [ ] 架构双语同步当前文档与只读预览的分离、完整图片加载、受保护恢复、重启协调和真实进程故障边界。
- [ ] Quickstart 双语同步可执行的验证旅程和命令，并明确浏览器语义结果不能替代真实进程重启/故障证据。
- [ ] 必要用户说明双语仅在 UI/入口已实现且对应验收证据存在后更新；不写逐操作日志、逐元素撤销或未验证的恢复成功承诺。
- [ ] 核对预览取消、切 Tab、迟到响应、缺图、只读、冲突和保护失败的文档描述与代码/测试一致。

### User Story 2：自动版本和手动标记：T026–T031

- [ ] IPC 契约同步 `history_mark`、历史问题事件或调度相关字段的实际接口；保留错误与当前文件保存结果分离的语义。
- [ ] 架构双语同步“成功冷检查点后生成”“约 30 分钟规则”“普通/保护最新 20 个共享池”“手动免自动清理”和无独立空闲唤醒等已验证行为。
- [ ] Quickstart 双语同步受控时钟、重启和回归命令，以及普通历史失败不等于当前文件保存失败的诊断边界。
- [ ] 必要用户说明双语只描述已实现且已验证的自动/手动行为；不把时间规则、容量限制或持久化失败处理写成未经证实的保证。

### User Story 3：清空、导入和 SDK 入口保护：T032–T037

- [ ] IPC 契约同步实际接入的保护替换目标、输入、错误和操作状态；不把未挂载或未验证的入口列为受保护入口。
- [ ] 架构双语同步统一替换引擎、操作前完整快照、文件/图片原子边界、公开 SDK 接入限制和外部竞争风险。
- [ ] Quickstart 双语同步已运行的键盘、拖放、导入/清空和故障验证命令；说明普通图片/Library 插入等非替换路径的实际边界。
- [ ] 必要用户说明双语只有在入口、取消、格式错误、焦点和保护失败行为均实现并验证后才更新；不宣传未达资格的命令面板或私有 DOM 路径。

### User Story 4：身份、生命周期和删除：T038–T044

- [ ] IPC 契约同步 `history_delete` 和实际生命周期/身份错误；不得让路径字符串、场景哈希或同路径新文件继承旧历史。
- [ ] 架构双语同步改名/移动、Save As、Workspace 卸载/重挂、外部替换、删除日志第三阶段、GC 引用保护和部分失败状态。
- [ ] Quickstart 双语同步生命周期、重启修复、删除和资源完整性验证命令；明确删除用户文件与删除应用历史的边界。
- [ ] 必要用户说明双语解释已实现的归属、保留、手动删除和失败反馈；不新增回收站、云备份或未批准的恢复流程。

## 单切片完成记录模板

在实现切片合并前，为每个实际受影响的文档保留以下信息（可写入对应证据或 PR 描述，不要把空模板复制到公共用户页面）：

| 字段 | 要求 |
| --- | --- |
| Slice / owner | 标识实现切片和唯一文档 owner；公共页面不写 private task 编号。 |
| Changed docs | 列出实际修改的 canonical 文件及中文 counterpart；IPC 契约若未改动须说明“未涉及”。 |
| Implemented fact | 用一句话说明已由代码支持的行为；不得写候选设计或未来计划。 |
| Evidence | 指向实际测试、运行报告或人工验收；缺失证据标为 `BLOCKED`，行为失败标为 `FAIL`。 |
| Boundary | 写明未覆盖平台、未验证路径、生产/测试构建差异和不支持能力。 |
| Readback | 确认 English/中文语义一致、稳定标识符未被翻译、没有空占位章节或秘密。 |
