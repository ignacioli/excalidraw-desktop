# ADR-005 官方画布样式与可扩展主题边界

**状态**：Accepted

**日期**：2026-08-10

## 背景/Context

产品目标是将成熟的 Excalidraw 画布体验转化为可靠桌面工具，而不是创建第二套编辑器视觉（R19/D7）。官方 `@excalidraw/excalidraw` 随包样式是画布 UI 的事实来源；桌面壳层需要对齐其浅色/深色视觉语言，同时为未来主题扩展划定安全边界。FR-035~037 要求三态外观偏好；DESIGN.md 定义了语义 token 与主题模型。

## 决策/Decision

1. **桌面壳层**：采用系统原生装饰窗口与传统桌面文档布局（顶部多文件标签、左侧文件管理、右侧画布）；不复刻官方 PWA 的浏览器顶栏、应用菜单、账号/云服务/协作入口。
2. **画布样式归属**：画布直接使用锁定 `@excalidraw/excalidraw` 包的公开样式与 `theme` 接口；业务代码仅经 `ExcalidrawAdapter` 访问官方 API；不复制上游私有组件或内部 CSS。
3. **主题模型**：主题家族 `themeId` 与模式偏好 `modePreference = light | dark | system` 分离；第一版仅注册 `excalidraw` 家族；运行时统一解析为 `light | dark` 并同时驱动壳层与官方画布。偏好为版本化前端本地状态，在首个用户可见界面前恢复；损坏或未知值回退 `system`。
4. **语义 token**：壳层消费 DESIGN.md 定义的语义 token（app-background、canvas-background、panel-background、surface-*、text-*、border-*、accent-*、focus-ring、danger/warning/success、shadow-floating、radius-*、space-*），初始值从锁定版本 Excalidraw 浅色/深色样式提取并在实现时记录对应包版本；不直接使用调色板字面值。
5. **扩展安全边界**：未来自定义主题只能提供经校验的语义 token 与基础明暗模式；禁止任意 CSS、选择器、脚本和远程资源。主题不进入 `.excalidraw` 文档；导出与缩略图契约继续只使用 `light | dark`，因此本决策不要求 data-model 或 IPC 迁移。

## 后果/Consequences

**积极**：

- 直接继承锁定包的公开样式，降低视觉漂移与上游升级成本。
- 主题家族与明暗偏好解耦，可在不改变文档格式或画布契约的前提下增加内置/自定义主题。
- 安全边界明确：无任意 CSS/脚本/远程资源，扩展风险可控。

**消极**：

- 第一版不提供用户自定义主题（主题导入、编辑器、分享与公开文件格式不属于第一版）。
- 壳层视觉受 token 调色板约束，精细视觉差异需回写 DESIGN.md 与 token 定义。
- 依赖锁定包的公开 CSS 变量边界，需要升级测试保护。

## 备选方案/Alternatives

- **Fork 官方 PWA**：完全控制权，但同步与安全补丁成本高，已由 R3 否决。
- **逐像素手工重画画布控件**：重复上游能力且易漂移，被否。
- **第一版即支持任意 CSS 自定义主题**：安全、兼容与维护边界不可控，被否。
- **现在将 Open Design 纳入日常生成主链**：当前属于参考驱动复刻，增加并行事实来源而无明显收益，仅保留为后续探索工具。
