# Local Version History design assets

This directory freezes the product-owner-approved low-fidelity interaction artifact and Penpot high-fidelity baseline for Local Version History.

- `interaction.md`: approved layout, semantics, actions, states, and accessibility behavior.
- `low-fi/local-version-history-t004.html`: self-contained OpenDesign prototype.
- `low-fi/manifest.json`: artifact identity and integrity.
- `high-fi/README.md`: approved Penpot baseline, scope, and implementation-reading policy.
- `high-fi/manifest.json`: Penpot file/page/frame identity, validation, approval, and archive integrity.
- `high-fi/source/excalidraw-desktop-uxui-redesign.penpot`: offline recovery snapshot of the approved editable source.
- `../../evidence/local-version-history-visual-checklist.md`: staged owner-review checklist.

Penpot remains the editable design carrier. The local archive is a recovery artifact and should not be decoded for ordinary implementation. Design approval does not substitute for exact-package production visual acceptance after T020 is implemented.
